# דשבורד הרכש החברתי של המדינה

לוח בקרה אחד, עצמאי, לעבודה על הרכש החברתי הממשלתי:

**[דשבורד רכש חברתי — גרסה מאומתת](dashboards/social_procurement_verified.html)** — תמונת מצב תקציבית, פטורים ומכרזים, ומפעילים וריכוזיות. מבוסס על קובצי נתונים אמיתיים: תקציב מאושר ומבוצע ברמת משרד ושנה, וייצוא רשומות פטור ורשומות מכרז פומבי ממנהל הרכש הממשלתי (`mr.gov.il`, 20.09.2026).

הקובץ הוא עמוד HTML עצמאי (ללא תלות בשרת) — ניתן לפתוח אותו ישירות בדפדפן.

## סטטוס נתונים — חשוב לקרוא לפני שימוש

כל מספר המתויג בממשק כ-"✓ מאומת" נבדק ישירות מול שדה מתאים בקובץ המקור, כולל מספרי התקנה המדויקים שעליהם יושבת כל עילת פטור. קובץ היצוא הגולמי עצמו (קובץ XML בשם xls, במשקל של כ-478 מגה-בייט) לא הוכנס לריפו הזה משום שהוא חורג משמעותית ממגבלת הגודל המקובלת להעלאת קובץ בודד ל-GitHub; הוא קיים כרגע רק בסביבת העבודה הזמנית שבה נבנה הקובץ. מי שירצה לשחזר את תהליך האימות או לבנות מחדש את הצבירות (לדוגמה כדי להוציא רשומות "כוונת התקשרות" מהספירה לפי עילה) יצטרך לקבל את קובץ המקור הזה מחדש, ואפשר לשקול החסנה שלו דרך Git LFS או כקובץ JSON מצומצם של הצבירות הגולמיות בלבד.

שני דשבורדים קודמים שהתבססו על אומדן להמחשה בלבד (ולא על נתונים אמיתיים) הוסרו מהריפו הזה, לאחר שהוחלט שהדשבורד המאומת מחליף אותם ככלי העבודה היחיד.

## מבנה הנתונים

הנתונים חיים inline בתוך קובץ ה-HTML (בתוך בלוק ה-`<script>`, באובייקטים כמו `BUDGET_DATA`, `EXEMPT_BY_GROUND`, `EXEMPT_BY_TOPLEVEL`, `EXEMPT_AMOUNT`, `TENDER_COUNT`, `REAL_SERVICES` וכו'), כדי לשמור על הדשבורד כקובץ עצמאי אחד. כדי לעדכן נתון — לערוך את האובייקט המתאים בקובץ.
